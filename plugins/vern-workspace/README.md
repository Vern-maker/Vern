# Vern 工作区插件

版本 0.1.0。可复用业务方法与模板，完整使用说明见 [仓库 README](../../README.md)。安装包内所有运行引用均位于本插件内部；本链接仅供源码仓库导航。

- `skills/`：七个业务入口及各自的交付结构、界面元数据。
- `references/`：共同规则、证据规范、任务字段、规范核验、试用用例和接入计划。
- `assets/templates/`：可复制的简报、任务台账、证据台账。
- `scripts/`：结构校验与案例目录创建工具，不自动访问外部系统。

`plugin.json` 为当前通用入口，`.codex-plugin/plugin.json` 提供 Codex 兼容元数据。完整插件一起安装，不单独移动 Skill 子目录，以免断开共享引用。
