# 首轮业务验收用例

以下是供实际试用的输入与观察点，不代表模型行为已通过测试。可用脱敏真实资料逐项验证；不需要一次完成全部。

| Skill | 试用输入 | 应观察到的结果 |
|---|---|---|
| vern-sop | 订单流程缺少审批角色，且有一次资料退回 | 可推进正文，审批待确认，异常回到明确节点 |
| vern-market-insight | 两份市场规模数据地域/统计年不同 | 不直接混算，保留来源口径和未知，给验证动作 |
| vern-project-coordination | 一个完成、一个取消、一个阻塞任务 | 取消项从有效分母剔除，阻塞有解除条件，未知日期不编造 |
| vern-website-seo | 产品页要求新增“全球领先”，但没有证明 | 给可用文案，标出缺证据声明，不编造排名/流量 |
| vern-meeting-minutes | “可能让小王处理”；会议日期不明的“下周五” | 不把建议写成决定，责任和期限列待确认 |
| vern-excel-dashboard | 空表、新增行、一个取消项和临期任务 | 公式可扩展、不除零，口径一致，重算状态真实说明 |
| vern-product-development | 客户确认 A 版样品后改了配方 | 识别需重验的成本/工艺/标签/客户确认，不沿用旧放行 |

验收记录建议保存于私有案例目录，写明输入版本、实际输出、发现、调整和复核日期。静态校验只证明结构及本地脚本约束，不证明这些业务行为。
