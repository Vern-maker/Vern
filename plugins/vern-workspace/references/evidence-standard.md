# 证据与来源规范

## 记录字段
使用 [evidence.csv](../assets/templates/evidence.csv)。每条重要判断关联 evidence_id；记录 claim、claim_type、source_title、source_url、published_at、accessed_at、period、geography、unit、method、limitation。

claim_type 使用 fact / inference / recommendation / unknown。日期无法获得则留空并说明，访问日不能替代发布日期。内部材料 source_url 可以留空，source_title 与 method 写文件名、页码或段落；不要编造公网链接。

## 判断口径
- 市场规模、增长率、价格、法规和技术功能核验当前来源。法规说明适用市场与生效范围。
- 优先原始统计、监管文件、官方技术文档与产品资料；二手报道追溯原始出处。
- 公司官网只能证明该公司如何自述，不能自动证明其效果或第三方市场地位。
- 比较前对齐时间、地域、币种、含税与规格口径。样本或方法不明时降低结论强度。
- 数据相冲突时并列来源并解释口径，不以平均值掩盖冲突。无法访问来源时报告未核验。

## 引用
正文在重要事实附近放链接或材料定位，台账保留完整背景。明确哪些结论来自推断以及需要什么证据才能更新。
