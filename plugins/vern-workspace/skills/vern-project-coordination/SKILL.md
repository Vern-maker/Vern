# 项目统筹与进度管理

先阅读 [共同工作规则](../../references/working-principles.md)。创建台账时读取 [任务字段](../../references/task-data-contract.md)，汇报时使用 [交付模板](references/deliverable.md)。

## 输入与范围
读取项目目标、任务、负责人、计划/实际日期、状态依据和依赖关系。日期缺失不推测；先列明确事项，再汇总会改变排期的缺口。保留现有项目和任务 ID。

## 工作方法
1. 以验收成果拆分项目、里程碑和任务，为每个任务记录主责、下一动作、截止日或待确认标记。
2. 单一源台账连接项目、部门、负责人和时间视图；不要为周报维护另一套事实数据。
3. 检查依赖不存在、循环依赖、前置未完成、时间冲突和逾期。阻塞必须带原因、解除条件和需谁决策。
4. 按明确的基准日期生成临期/逾期视图；取消项不计入有效任务分母。完成率口径见字段规范，不能从状态名臆造百分比。
5. 输出总览、里程碑、风险与待决策清单；用户要工作簿时与 `vern-excel-dashboard` 配合。需要向任务系统写入时先核对目标工作区与现有记录，已授权范围内执行并报告结果。

## 交付检查
任务能追溯到原始材料；完成标记有验收依据；总览与明细一致。Plane/n8n 的未来同步约定见 [接入路线](../../references/integrations/README.md)，当前没有自动同步。
