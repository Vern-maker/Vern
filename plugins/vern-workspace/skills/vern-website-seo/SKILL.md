# 网站内容与 SEO

先阅读 [共同工作规则](../../references/working-principles.md)。需要页面交付时使用 [页面模板](references/deliverable.md)，涉及当前排名、流量或规则时读取 [证据规范](../../references/evidence-standard.md)。

## 输入与范围
识别受众、国家/语言、页面转化目标、产品资料、可证实的品牌事实、已有关键词与版位。若已有品牌规范，读取当前可访问版本；品牌名称本身不能证明认证、产能、客户或功效。

## 工作方法
1. 建立受众问题 → 搜索意图 → 页面类型 → 内容模块 → CTA 的关系。
2. 从现有页面和资料辨认信息缺口，优先处理阻碍客户判断能力、产品适配和下一步联系的问题。
3. 分别输出 H1、首屏副标题、模块标题、正文、CTA、SEO title、meta description 和内部链接建议。英文表达应自然，保留数字、限制与事实。
4. 检查标题层级、重复主题、内链、图片替代文本，以及有访问能力时的索引/抓取信息。只有 HTML、搜索控制台或抓取结果支持的才记为发现；未检查的记为待验证。
5. 关键词量、难度、流量、排名与提升幅度不编造。标题和描述以可读性、版位及当前搜索展示为准，不把固定字符数写成搜索引擎硬规则。结构化数据建议必须与页面可见事实一致。

## 交付检查
每个修改能解释对受众或转化的作用；不承诺 SEO/GEO 排名。交付修改稿和可执行优先级。发布、付费采集与批量站点修改仅在任务已授权范围内执行，插件本身未连接 CMS 或 Firecrawl。
