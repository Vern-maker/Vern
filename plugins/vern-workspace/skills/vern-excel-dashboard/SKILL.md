# Excel 与经营看板

先阅读 [共同工作规则](../../references/working-principles.md)。项目类表格读取 [任务字段](../../references/task-data-contract.md)，制作文件前使用 [工作簿设计与验收](references/deliverable.md)。

## 输入与范围
检查原文件、字段含义、数据量、使用者、Excel 版本、刷新频率和指标口径。保留用户现有公式与样式约定，先辨别输入、公式和导入数据。缺少公司数据时提供空白模板，演示数据必须显著标识且与真实数据隔离。

## 工作方法
1. 定义数据字典和唯一 ID，日期/数字使用真实数据类型，金额保留币种。先处理重复、缺失、口径冲突，不能静默删行。
2. 设计源表、参数/字典、汇总、仪表盘和使用说明；按规模合并不必要的工作表。跨表引用回到同一源表。
3. 用可扩展表格、公式、数据验证、条件格式、筛选和冻结提高维护性；避免固定范围遗漏新增行。明确手填区与计算区。
4. 核对筛选条件、分母、空值、取消任务、日期基准和异常状态。图表标明时间范围、单位及数据截至日。
5. 如当前环境有表格文件 Skill/工具，使用其保存、计算和渲染能力；否则用可用库制作文件。生成文件不等于公式已计算，有计算引擎时重算，无法重算时说明未验证的缓存值。

## 交付检查
用正常、空白、新增行、逾期和取消等有代表性情形检查。核对公式错误、总计和图表范围；预览版面。交付可编辑文件和使用说明，披露刷新限制，不宣称已连接实时系统。
