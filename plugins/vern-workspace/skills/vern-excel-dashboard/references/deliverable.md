# 工作簿设计与验收

| 工作表 | 作用 | 手填/计算 | 唯一键/来源 | 更新方式 |
|---|---|---|---|---|
| 使用说明 | 口径、更新步骤、限制 | 说明 | 当前版本 | 随结构变更 |
| 源数据 | 单一事实台账 | 输入/导入 | 业务 ID | 追加/更新 |
| 字典参数 | 状态、阈值、基准日 | 输入 | 参数名 | 明确变更 |
| 汇总看板 | 指标与可视图表 | 计算 | 源数据 | 重算/刷新 |

按任务数完成率示例（Excel 表名 Tasks）：

```excel
=IF(COUNTIF(Tasks[task_id],"<>")-COUNTIF(Tasks[status],"cancelled")=0,"",COUNTIF(Tasks[status],"done")/(COUNTIF(Tasks[task_id],"<>")-COUNTIF(Tasks[status],"cancelled")))
```

前提：task_id 每行非空且唯一，status 已验证，无空白占位行；否则先清洗或按有效 ID 限定统计。此指标不是工时或产值完成率。

## 交付前验收
检查新增行自动纳入、全空数据不出现除零、取消任务不计有效分母、逾期按基准日期变化、单位与币种一致、公式未被文本替代。

说明重算环境和结果：已重算/仅静态检查/需用户在 Excel 刷新。不能把未重算缓存为空误判为零。
