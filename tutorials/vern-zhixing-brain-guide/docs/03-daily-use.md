# 03｜执行与沉淀

## 开始前

读取任务卡与当前有效资料。使用一个有区分度的短词查找相关记录，核对来源、日期和适用条件。未找到资料时说明缺口，不补造历史。

可使用以下任务表达：

> 基于我提供和授权查阅的资料完成这个任务。先核对相关方法与已确认结论，保留数字和约束，区分事实与建议，交付可编辑结果并说明验收情况。

## 执行中

保持单一源数据，复用现有格式。遇到异常写明原因、影响、恢复条件和下一步。范围变化同步更新任务卡，避免结果与原目标脱节。

涉及对外发送、发布、交易或重要配置时，核对授权范围和具体内容。结果未知时先核实实际状态，再决定是否重试。

## 完成后

记录交付物、检查结果、未验证事项和后续动作。用 [复盘记录](../templates/review.md) 说明哪些做法有效，哪些需要调整。

每日整理只归纳有真实材料支持的活动。旧成果保留原日期；资料不足的事项留下待总结。
