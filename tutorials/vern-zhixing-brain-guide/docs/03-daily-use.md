# 03｜日常使用与沉淀

## 开始任务

向执行工具说明目标、当前资料、交付格式、允许读取的位置及限制。例如：

> 先查阅我授权知识库中的相关方法和证据，再整理这份材料。区分已确认事实、建议和待确认事项，给出可编辑结果与核查说明。

检索使用一个有区分度的短名词。命中后读取有效来源；未命中时记录缺口，不把候选提示当成证据。

## 完成任务

检查结果是否保留数字、限制和来源，是否可直接使用，是否经过与风险相称的验收。记录完成内容、证据、日期、失败原因和下一步。

## 沉淀经验

把一次性事实与可复用方法分开。方法须写明适用条件、步骤、例外及验收依据；新的经验先作为待验证候选。同类任务中经使用者采用，并在交付验收后，才确认其适用性。

每日整理只处理授权范围中的真实资料。资料不足时留下待总结，不编造经历，不自动导入所有聊天记录。
