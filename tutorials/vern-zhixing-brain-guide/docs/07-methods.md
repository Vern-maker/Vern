# 07｜方法卡与经验

一次任务的完成记录证明当次发生了什么；方法卡说明下一次怎样做。

一张方法卡包含适用问题、必要输入、操作步骤、交付物、检查方法和例外。优先写能执行的动作，保留失败处理。

## 确认经验的步骤

1. 从已验收任务中提取具体做法及支持证据。
2. 标明仍需验证的适用条件，作为候选方法保存。
3. 在同类任务中选择采用，记录实际效果。
4. 交付通过验收后，确认此次证明的适用范围。
5. 新证据改变条件时更新、限制或停用旧方法。

工具中的 Skill 可以承载方法卡。规则应与模板及引用文件一致，同名方法有差异时先比较。安装入口与实际任务效果分别检查。

不把空模板当成个人经验，也不因使用次数增加就自动扩大方法的适用范围。
