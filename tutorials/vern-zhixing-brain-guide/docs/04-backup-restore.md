# 04｜备份与换电脑恢复

## 备份范围

分别备份自己的知识库及附件、Skills 与引用文件、工作规则、程序版本与依赖记录，以及必要的检索配置。凭据使用独立安全方式管理。公开教程不能代替私人备份。

复制前确认源位置、目标位置和剩余空间。保留原文件，核对文件数量与哈希；不要只备份笔记而漏掉附件或方法的引用文件。

## 新电脑恢复顺序

1. 安装工具并重新登录。
2. 按上游说明安装程序，确认平台兼容。
3. 恢复私人资料，确认没有重复嵌套目录，随机打开笔记和附件。
4. 合并自己的工作规则与方法；已有不同内容先比较。
5. 重新配置检索并确认来源有效。
6. 完成手动验收，再注册新电脑的自动任务。

旧任务的运行状态不自动适用于新电脑。核对新电脑的时区、用户身份、权限、运行日志和真实产物。恢复成功前保留原备份。
