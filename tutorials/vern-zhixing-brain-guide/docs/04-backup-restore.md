# 04｜备份与恢复

分别保存自己的知识资料及附件、方法卡与引用文件、工作规则、必要配置和恢复说明。凭据独立管理。

备份前确认源位置、目标位置和空间，保留原文件。核对数量或哈希，抽查笔记、附件和方法引用。定期实际尝试一次恢复。

## 恢复顺序

1. 准备目标环境和访问权限。
2. 在新位置恢复资料，保留原备份。
3. 检查文档与附件可打开，引用可找到。
4. 合并自己的规则和方法，差异先比较。
5. 用一个无敏感内容的任务验证查阅、执行和输出。
6. 验证完成后再恢复提醒、同步或自动任务。

恢复资料与恢复工具分开验收。文件存在还须确认内容完整；工具可登录还须确认能访问授权资料并产生正确结果。
