# 05｜故障与纠错

| 问题 | 检查证据 | 修正动作 |
|---|---|---|
| 找不到资料 | 用词、位置、访问权限 | 缩小问题，检查实际来源 |
| 使用了旧结论 | 日期、有效状态、纠错记录 | 标明失效结论并引用更新依据 |
| 输出与需求不符 | 任务卡、输入、完成标准 | 修正范围或执行步骤 |
| 数字不一致 | 源数据、口径、公式 | 统一主要记录并重新核对 |
| 提醒执行但没有成果 | 执行历史、错误记录、实际文件 | 分别检查触发、执行和写入 |
| 文件恢复不完整 | 数量、附件、引用、哈希 | 从保留的备份补齐并重新检查 |

纠错记录写明原判断、错误原因、当前结论、证据和影响范围。涉及多个成果时同步修正，避免不同文档继续引用不同版本。

不把状态标签当作成功依据。发生不确定结果时先核查，保留可恢复资料，并防止重复动作。
