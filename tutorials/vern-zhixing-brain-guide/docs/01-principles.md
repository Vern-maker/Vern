# 01｜工作原理

把工作分成三个互相衔接的对象：任务说明要完成什么，证据支持为什么这样判断，方法说明怎样执行与检查。

| 对象 | 最少记录 | 更新时机 |
|---|---|---|
| 任务 | 目标、输入、交付物、完成标准、下一步 | 开始、范围变化与完成时 |
| 证据 | 来源、日期、事实、限制、有效状态 | 新资料出现或旧结论失效时 |
| 方法 | 适用条件、步骤、例外、验收方式 | 经过实际使用和复盘后 |

先明确目标，再查阅当前有效证据，选择方法并执行。成果经检查后形成工作记录；其中能重复使用的做法才进入方法库。

同一事实保持一份主要记录，报告和看板引用它。发现冲突时保留原记录与修正依据，标明哪些结论已失效。

自动整理只负责辅助归纳。资料不足时记录缺口；经验是否可用由真实任务与验收结果决定。
