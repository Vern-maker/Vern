# 10｜公开插件与扩展

[Vern-maker/Vern](https://github.com/Vern-maker/Vern) 已有独立的分享版插件。请从仓库首页读取安装说明与能力介绍；本阅读版不复制个人方法目录。

克隆仓库或看到文件，不代表插件已安装进当前会话。安装后在新聊天中使用非敏感输入，核对入口、引用文件和交付结果。

新增外部工具时，每次验证一个链路：真实输入 → 授权动作 → 可核查输出 → 失败处理，再连接下一项。检查账号权限、额度、数据去向和人工审批条件。

仓库既有 Mermaid、MarkItDown、n8n、Firecrawl、Plane 入口属于规划，具体状态见插件 registry。规划入口不能被视为已经接通或已在新电脑恢复。
