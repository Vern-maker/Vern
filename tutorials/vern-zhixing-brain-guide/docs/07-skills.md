# 07｜管理自己的 Skills

公开版不提供个人 Skills 名称、数量、能力目录或原始正文。

按任务选择少量相关方法。每个方法说明适用目标、必要输入、步骤、交付检查和依赖引用。已有格式优先，不把方法偏好当成业务事实。

升级前保留旧版本并比较差异。引用文件须随方法一同保留；安装后在新会话中验证入口。避免多个位置出现同名、规则不同的方法。

可公开分享通用方法和空模板；业务信息、公司内部规则及个人历史保留在授权的私人空间。

编写与安装约定参考 [Codex Skills 文档](https://developers.openai.com/codex/skills/)。
