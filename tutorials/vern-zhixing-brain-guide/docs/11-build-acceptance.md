# 11｜搭建验收与恢复

## 发布包验证

本版本验证初始化、已有目标保护、中文检索、BOM 读取、无匹配、失效记录过滤及只读行为。原生符号链接越界测试因权限限制跳过。具体结果见 [验证记录](validation.md)。

## 在自己电脑逐项验收

| 动作 | 预期结果 |
|---|---|
| 检查 Python | 版本满足要求 |
| 初始化新目录 | 返回 initialized，建立模板与演示资料 |
| 同一目标再次初始化 | 拒绝，原资料内容保持不变 |
| 检索演示规则 | 显示 example 状态和对应文件 |
| 检索无关词 | 零条命中，不编造结果 |
| 在 Codex 打开工作空间 | 能实际读取任务规则和资料 |
| 执行真实任务 | 有可使用成果和检查记录 |
| 从备份恢复到新位置 | 模板、资料、引用与检索仍可用 |

## 失败恢复

找不到 Python 时先确认安装和命令名称。初始化目标存在时保留内容，选择新目录；不要覆盖。检索为空时检查资料是否放在内容区、是否为 UTF-8 Markdown、是否被标为失效。

Codex 未读取规则时，确认当前目录和文件名，并在新聊天显式要求读取。检索脚本只返回线索，仍需读实际来源。

初始化中途失败可能留下部分新文件；保留现场并核对错误，再在新目录重建。备份恢复时先抽查，确认成功后再切换工作目录。
