# 06｜验收清单

以下为使用者在目标环境执行的检查，不代表本公开版已替你完成。

| 层次 | 通过依据 |
|---|---|
| 工具与依赖 | 程序能够启动，依赖可用 |
| 登录 | 目标机器账户状态有效 |
| 检索 | 无敏感示例能定位预期来源，来源存在且有效 |
| 方法 | 输入、执行步骤与交付检查可以走通 |
| 输出 | 结果对应输入，事实与建议清楚，交付可编辑 |
| 调度 | 任务身份、时间、执行历史与退出码可核查 |
| 写入 | 授权范围内出现实际产物，内容有真实证据 |
| 恢复 | 笔记、附件、方法引用与配置完整 |

出现失败时记录现象和证据，保留旧资料。未完成的项目写待验证。不得用登录状态或任务注册状态替代全链路成功。
