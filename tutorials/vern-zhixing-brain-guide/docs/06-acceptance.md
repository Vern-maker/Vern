# 06｜验收清单

| 检查项 | 通过依据 |
|---|---|
| 目标 | 成果对应任务目标与范围 |
| 事实 | 关键结论可以追溯到有效来源 |
| 数字 | 数据、口径、计算与限制可核查 |
| 格式 | 交付可打开、可阅读、可修改 |
| 使用 | 接收者能理解输入要求与更新方法 |
| 异常 | 失败原因、处理动作与恢复条件明确 |
| 状态 | 完成标记有实际成果和检查依据 |
| 复用 | 方法适用条件、例外与验收方式齐全 |

检查深度与任务影响相称。简单文字修改核对保真与可读性；计算、自动化或对外发布还须验证关键行为和实际结果。

记录通过、失败与待验证项目。验收未通过时继续修正或明确阻塞原因，不用计划、账号状态或运行提示替代结果。
