# 02｜搭建方案：Vern 本地工作空间

目标：在 Windows 上建立能查资料、执行任务、保存方法和记录复盘的最小系统。首次搭建先验收手动工作循环。

## 组成与准备

| 组成 | 用途 | 要求 |
|---|---|---|
| 本教程包 | 方法、模板与本地脚本 | 下载并解压 |
| Python | 执行初始化和检索 | Python 3.10 或以上，无额外库依赖 |
| Codex 或自己使用的执行工具 | 读取资料并完成任务 | 可访问你授权的工作目录 |
| Markdown 编辑器 | 编辑笔记和方法 | 普通文本编辑器即可；Obsidian 可选 |

本包只创建本地文件。检索脚本只读指定内容区；AI 使用、外部传输与自动任务均须另行配置和授权。

## 第一步：检查 Python

在 PowerShell 运行：

```powershell
py -3 --version
```

应为 3.10 或以上。如果已安装 Python 但没有 `py`，可以使用 `python --version`，随后将命令前缀替换为 `python`。

## 第二步：初始化新工作空间

在 PowerShell 进入教程解压目录。目标由自己选择，必须是尚不存在的新文件夹：

```powershell
$workspaceRoot = Read-Host '输入新工作空间的完整路径'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Initialize.ps1 -Root $workspaceRoot
```

没有 `py` 时：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Initialize.ps1 -Root $workspaceRoot -PythonCommand python
```

也可直接用 Python：

```powershell
python .\scripts\initialize.py --root $workspaceRoot
```

现有目标会被拒绝。初始化失败时检查错误并保留已创建内容，不要删除已有资料重试。

### 本包创建的全新通用结构

| 内容 | 用途 |
|---|---|
| 资料 | 授权输入与证据，含一条明确标记的演示资料 |
| 任务 | 任务卡、进展与下一动作 |
| 方法 | 经过验证的做法与待验证候选 |
| 复盘 | 成果检查、纠错与经验提炼 |
| templates | 三种空白卡片 |
| tools | 只读检索脚本 |
| AGENTS.md | 本工作空间的任务规则 |

这是本教程新建的空白模板，不包含作者的私人结构、资料或配置。初始化不会修改全局规则、安装插件、联网或开启自动化。

## 第三步：验证本地检索

```powershell
py -3 (Join-Path $workspaceRoot 'tools/search.py') --root $workspaceRoot --query '演示规则'
```

预期找到一条演示资料，状态为 `example`，并显示相对文件名、行号和短摘录。该结果验证检索可用，不代表已有个人知识。

检索为字面匹配，支持中文；不会调用模型或做语义搜索。无匹配时返回零条结果。每次最多返回指定数量，默认五条。已失效记录会跳过；草稿和状态未指定的资料仍会显示，使用前必须核查。

## 第四步：接入 Codex

将新工作空间作为 Codex 当前项目或工作目录，开启新聊天，明确要求：

> 请读取本工作空间根目录 AGENTS.md，列出你将遵循的任务规则，再检索“演示规则”，说明来源和状态。

确认能读取规则、运行检索并定位实际资料。修改规则后新开聊天核对；不能仅凭文件存在认定接入成功。项目内规则的发现机制参考 [官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。

## 第五步：完成一个真实任务

1. 只将明确授权的资料加入“资料”。
2. 从 `templates/task-card.md` 复制任务卡到“任务”，补齐目标、交付物和完成标准。
3. 要求执行工具先查相关资料，再完成任务；输出放在你指定的位置。
4. 按完成标准验收，将结果保存为“复盘”记录。
5. 有复用价值的做法写入“方法”，标明适用条件与验证状态。

建议用三天完成：第一天初始化与演示检索，第二天做完一项真实任务，第三天复用一次并检查方法是否有效。该安排是搭建建议，日期由使用者确定。

## 第六步：备份和后续扩展

按备份页保留整个工作空间。优先完成手动流程，再决定是否增加提醒、同步和自动整理。

当前脚本没有自动总结或定时功能。可先用手动日终提示：

> 核对今天已完成任务与复盘，只基于可找到的真实证据整理工作记录；缺失资料列为待总结。提出候选方法，不自行确认生效。

自动化方案须另外明确运行身份、时间、读取和写入范围、错误处理与真实产物验收。
