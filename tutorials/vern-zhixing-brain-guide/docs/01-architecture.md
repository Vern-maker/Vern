# 01｜工作原理

Skills 保存可复用的做法，Markdown 知识库保存已确认事实与证据，工作规则说明何时读取它们。检索工具帮助定位相关来源，Codex 根据任务和来源完成交付。

基本循环：任务 → 读取方法与证据 → 执行 → 验收 → 记录事实 → 人工复核可复用经验。

自动整理不会训练模型。没有真实资料时，应留下资料缺口，不能把模板、旧成果或任务运行状态当成新经验。

## 各组件的责任

| 组件 | 责任 |
|---|---|
| Codex | 读取授权资料、执行任务、生成结果 |
| Skills | 约定输入、方法、交付物和检查标准 |
| Markdown 知识库 | 保存来源、决定、成果与复盘 |
| 检索工具 | 定位可核查来源并提示缺口 |
| 定时任务 | 在限定范围内触发整理 |

知识库的具体目录、个人方法清单和路由配置由使用者自行管理，本公开版不提供原环境结构。

自动任务的写入范围必须明确。外部方法、全局配置和凭据的修改需要另行授权。发生冲突时交给使用者决定。
