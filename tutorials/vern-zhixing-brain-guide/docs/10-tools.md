# 10｜工具选择

先完成工作循环，再按实际瓶颈选择工具。

| 工作需要 | 可选择的工具类型 | 使用前检查 |
|---|---|---|
| 记录与查阅知识 | 文档或笔记工具 | 易编辑、可备份、能查找 |
| 执行与生成成果 | AI 或专业编辑工具 | 输入范围、权限、可核查输出 |
| 计算与汇总 | 表格工具 | 单一源数据、公式、更新方式 |
| 跟踪动作 | 任务或项目工具 | 主责、期限、状态依据 |
| 周期整理 | 提醒或自动任务 | 运行范围、错误记录、真实产物 |

每次只验证一条链路：输入 → 授权动作 → 实际输出 → 验收 → 失败恢复。通过后再连接下一项。

Vern 仓库提供可选的公开工作方法插件，入口见仓库首页。是否采用由任务需要决定；规划能力、安装状态与实际效果分别核对。
