# 05｜故障排查

| 现象 | 先检查 | 处理方向 |
|---|---|---|
| 工具不能启动 | 官方安装、可执行文件、依赖 | 核对当前版本与平台要求 |
| 登录不可用 | 登录状态、网络、账号权限 | 在目标机器重新授权 |
| 检索未命中 | 用词、文件存在性、配置 | 使用短名词，检查实际来源 |
| 读到旧结论 | 日期、有效状态、纠错记录 | 优先采用当前有效来源 |
| 已注册但没产物 | 任务历史、退出码、日志 | 分别检查触发、调用与写入 |
| 状态页与事实冲突 | 编码、解析、更新时间 | 核对底层日志和实际文件 |
| 恢复内容冲突 | 同名文件与差异 | 保留副本，人工合并 |

Markdown 元数据读取须处理 UTF-8 BOM 等编码问题。状态页只能作为线索，不能替代操作系统查询、真实调用记录与产物验收。

不通过输出密钥来排查问题。公开日志前移除凭据、用户路径、笔记标题、内容与业务身份信息。
