# Vern 知行工作法

一套把资料转化为行动、把成果转化为可复用经验的工作方法。

工作主线：**明确任务 → 查阅证据 → 选择方法 → 执行交付 → 验收记录 → 复用改进**。

## 先完成一次完整循环

1. 选一个范围清楚的真实任务，写明目标、输入、交付物和完成标准。
2. 查阅自己已确认的资料，记录来源与有效日期；缺失信息列为待确认。
3. 选择适用方法，完成可编辑、可维护的成果。
4. 按标准检查结果，记录通过、失败和仍未验证的部分。
5. 只把有证据支持、可以重复使用的做法提炼为经验。

可以先用普通文档和文件夹执行，随后按需要加入知识管理、AI、表格或任务工具。

## 三项基本要求

**事实可追溯。** 区分事实、推断、建议与待确认事项，保留数字、约束和来源。

**成果可验收。** 交付物应能使用、修改和维护；完成标记必须有检查依据。

**经验有条件。** 记录适用范围与例外，经过使用和验收再确认可复用性。
