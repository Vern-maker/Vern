# Vern 知行脑公开教程：脱敏阅读版

把工作方法交给 Skills，把经过确认的知识保存在 Markdown 知识库，执行任务前查阅证据，完成后记录结果。

本版依据用户要求删除个人路径、知识库结构清单、个人 Skills 名称与能力目录、路由字段说明及原环境版本验收摘要。仅提供通用教程；不包含个人数据、私人恢复包、安装器、补丁或源码快照。

## 开始使用

先按搭建页获取官方工具和上游程序，再用一条无敏感内容的示例完成检索与输出验收。个人知识库和方法文件须自行保管、备份和恢复。

本阅读版没有一键安装功能，也不替代上游安装说明。程序安装不代表旧知识已恢复；登录成功不代表模型已经完成写入；任务已注册不代表产物有效。

## 获取程序与公开方法

- [DSH-KRouter 上游仓库](https://github.com/398894496-arch/DSH-KRouter)：程序与上游使用说明。Windows 用户须核对其当前平台支持，不直接执行面向其他系统的安装脚本。
- [Vern 公开插件](https://github.com/Vern-maker/Vern)：分享版工作方法及独立安装说明。
- [Codex Skills 文档](https://developers.openai.com/codex/skills/)与[工作规则文档](https://developers.openai.com/codex/guides/agents-md/)：入口与配置约定以当前官方文档为准。

本教程核查范围见来源页。外部工具的当前版本、账号权限与新电脑运行状态，需要在目标环境重新确认。
